# ADR 0001 — Registrar decisões arquiteturais

**Status:** aceita

## Contexto
O projeto parte de três documentos-base e vai desviar deles quando houver evidência (protótipos em Windows real). Sem registro, o motivo das decisões se perde.

## Decisão
Toda decisão relevante ou desvio dos documentos-base vira um ADR curto em `docs/adr/`, numerado sequencialmente, e o documento afetado é atualizado junto.

## Consequências
Histórico rastreável; pequeno custo de escrita a cada decisão.
